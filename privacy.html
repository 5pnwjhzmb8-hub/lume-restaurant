2. Datos que se pueden recoger

A través del sistema de reservas pueden solicitarse datos como nombre, teléfono, correo electrónico, fecha, hora y número de personas.

3. Finalidad

Los datos se utilizan para gestionar las solicitudes y reservas realizadas a través del sitio web.

4. Base jurídica

La base jurídica del tratamiento será determinada de acuerdo con la finalidad concreta del tratamiento y la normativa aplicable.

5. Conservación

Los datos se conservarán durante el tiempo necesario para gestionar la reserva y durante los plazos que puedan resultar legalmente exigibles.

6. Proveedores tecnológicos

El sitio web utiliza servicios tecnológicos externos necesarios para determinadas funciones, incluyendo el sistema utilizado para gestionar las reservas.

7. Derechos

Las personas interesadas pueden ejercer los derechos de acceso, rectificación, supresión, oposición, limitación del tratamiento y, cuando proceda, portabilidad de sus datos.

8. Reclamaciones

Las personas interesadas pueden presentar una reclamación ante la Agencia Española de Protección de Datos cuando consideren que el tratamiento de sus datos no se ajusta a la normativa aplicable.

9. Actualizaciones

Esta política podrá actualizarse cuando resulte necesario.
